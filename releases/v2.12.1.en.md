# Prompt Optimizer v2.12.1

## Summary
Fix Windows TikTok product-card model configuration selection.

## Highlights
- Choose any enabled text model configuration using the same selector as the home page.
- Keep quick switching among models within the chosen configuration.

## Product Updates
### Desktop
- Include searchable configuration selection and a text-model management shortcut.
### Web
- No change to existing product-card behavior.
### Core/Infra
- Add regression coverage for configuration selection and the model key used by generation and history.

## Fixes
- Previously only the current configuration's internal model could be changed; the configuration-level selector was missing.

## Breaking Changes / Upgrade Notes
- No data migration. Existing configurations and product-card history are retained.
- Windows x64 NSIS only, with automatic-update metadata. The installer is unsigned.

## Developer Notes
- Reuse SelectWithConfig and the existing enabled-model source; no changes to prompts, collection or provider configurations.
