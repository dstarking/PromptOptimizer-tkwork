# Prompt Optimizer v2.12.3

## Summary
Make Windows product-card generation visible while the model responds.

## Highlights
- Stream text into a live preview, with waiting, processing, receiving, validation and repair states.
- Preserve partial content on failure and show readable structured errors.

## Product Updates
### Desktop
- Remove brand input, authorization checkbox and authorization preflight.
- Omit brand attribute lines from new prompts; do not request brand or authorization copy.
- Keep existing title, description, main image and video modules after successful validation.
### Web
- Unchanged.
### Core/Infra
- Reuse the existing streaming and error utilities; no new provider interface.

## Fixes
- Replace object-string errors with actual error details.
- Save history only after a valid result; ignore superseded generation callbacks.

## Breaking Changes / Upgrade Notes
- Old history remains readable. No migration or deletion.
- Windows x64 NSIS only, unsigned, with automatic-update metadata.
- Streaming does not guarantee provider availability, vision support or valid JSON.

## Developer Notes
- Both initial generation and one-time video repair are streamed.
- Existing SKU confirmation, image handling and actual product logos are retained.
