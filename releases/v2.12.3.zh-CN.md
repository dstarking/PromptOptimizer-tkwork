# Prompt Optimizer v2.12.3

## 概括
Windows 商品卡在模型响应期间显示流式生成内容。

## 亮点
- 实时预览文本，显示等待、处理、接收、校验及修复阶段。
- 失败时保留部分内容，显示真实结构化错误。

## 产品更新
### Desktop
- 移除品牌输入、授权勾选与授权预检查。
- 新请求过滤品牌属性行，不要求生成品牌名称或授权声明。
- 校验成功后仍展示标题、描述、主图与视频模块。
### Web
- 无改动。
### Core/Infra
- 复用现有流式接口和错误工具，无新供应商接口。

## 修复
- 不再将结构化错误显示为对象字符串。
- 仅完整有效结果保存历史，已失效请求的回调不回填。

## 破坏性变更 / 升级说明
- 旧历史兼容，无迁移或删除。
- 仅 Windows x64 NSIS，未签名，包含自动更新元数据。
- 流式输出不保证供应商可用、支持图片或返回有效 JSON。

## 开发者说明
- 首次生成和一次视频修复均采用流式接口。
- 保留 SKU 确认、图片处理和商品真实 Logo，不修改图片。
