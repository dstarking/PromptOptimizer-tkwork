# Prompt Optimizer v2.12.0

## 概括
新增 Windows 桌面商品卡增强功能：受控 1688 采集、SKU 核对及四项英文输出。

## 亮点
- BrowserSkill 复用已登录 Chrome，每次采集使用独立会话。
- 视频总时长支持 10、15、20、25、30 秒，程序校验连续时间轴。
- 独立辅助合规规则检查不实宣称、品牌授权和供应商信息泄漏。

## 产品更新
### Desktop
- 采集商品资料，选择目标 SKU、核对或更正事实，导入匹配展示图或手动上传原图。
- 分块输出标题、描述、主图提示词和视频分镜；支持复制、导出、收藏与版本化历史。
### Web
- 原有三项输出和提示词保持不变，不开放本地系统命令。
### Core/Infra
- 新增商品证据类型、时长校验和合规规则，发布仅构建 Windows NSIS 安装包。

## 修复
- 保留旧历史读取，避免导入已知不匹配 SKU 的参考图。
- 在桌面入口将 CDN WebP 展示图无损转换为 PNG，兼容现有参考图处理流程。
- 更新源指向 dstarking/PromptOptimizer-tkwork，并补齐双语版本说明。

## 破坏性变更 / 升级说明
- 需独立安装 BrowserSkill CLI 和扩展，先运行 bsk daemon start --foreground。
- 自动导入图片为展示副本，未验证为供应商原图；不保证完整详情图库采集。
- 合规规则为辅助检查，不是官方发布许可；SEO 推荐不是已验证的实时热词。
- 本版本仅提供 Windows x64，不构建 macOS、Linux、扩展 ZIP 或 Windows 便携 ZIP。
