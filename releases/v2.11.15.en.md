# Prompt Optimizer v2.11.15

## Summary
- Limits TikTok product-card output to three final assets.
- Returns one optimized English title and one optimized English product description.
- Internally compares several main-image directions and returns only the strongest prompt.
- Filters unrequested numbered sections, preambles, and repeated result sections from the UI.

## Highlights
TikTok product-card results are now focused on the three assets needed for publishing instead of exposing intermediate analysis, SEO lists, gallery plans, or alternative image concepts.

## Product Updates
### Web
- Displays the three result blocks with Chinese interface titles while keeping final product-card content in English.
- Keeps optional seller title, specification, and supplier-description inputs as supporting evidence.

## Fixes
- Removed product identification, keyword lists, nine-image plans, CTR analysis, A/B tests, and seller-confirmation sections from new product-card results.
- Prevented extra numbered model sections and repeated supported sections from being rendered as additional result content.

## Breaking Changes / Upgrade Notes
- Newly generated TikTok product cards now use a three-section result contract. Older fourteen-section output is no longer generated.

## Developer Notes
- The result parser now uses all numbered top-level headings as content boundaries but exposes only the three supported section keys.
- Prompt and parser regression tests cover the reduced output contract.
