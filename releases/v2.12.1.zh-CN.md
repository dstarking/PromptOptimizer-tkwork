# Prompt Optimizer v2.12.1

## 概括
修复 Windows TikTok 商品卡无法切换不同模型配置的问题。

## 亮点
- 复用首页下拉框，选择任意已启用的文本模型配置。
- 保留所选配置内部的模型快切。

## 产品更新
### Desktop
- 支持搜索配置，并提供现有文本模型管理入口。
### Web
- 商品卡原有行为不变。
### Core/Infra
- 增加配置切换、生成请求和历史记录使用正确配置的回归测试。

## 修复
- 之前只有当前配置内部的模型快切，缺少配置级选择控件。

## 破坏性变更 / 升级说明
- 无数据迁移，保留已有模型配置与商品卡历史。
- 仅发布 Windows x64 NSIS 安装包和自动更新元数据；安装包未签名。

## 开发者说明
- 复用 SelectWithConfig 和已启用配置数据源，不修改提示词、采集或供应商配置。
