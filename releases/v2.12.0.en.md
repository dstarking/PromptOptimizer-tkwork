# Prompt Optimizer v2.12.0

## Summary
Windows desktop product-card enhancement with controlled 1688 import, SKU confirmation and four English outputs.

## Highlights
- BrowserSkill uses independent sessions in the existing logged-in Chrome profile.
- Total video duration supports 10, 15, 20, 25 and 30 seconds with checked continuous timelines.
- Independent advisory compliance rules flag unsupported claims, brand authorization and supplier content.

## Product Updates
### Desktop
- Import real product data, select a target SKU, correct facts, and import matching display-image references or upload originals manually.
- Four blocks: title, description, main-image prompt, video storyboard/prompts. Copy, export, favorites and versioned history remain available.
### Web
- Existing three-block prompt and behavior are unchanged; local commands are unavailable.
### Core/Infra
- Add product evidence types, timeline validation and compliance checks. Release builds Windows NSIS only.

## Fixes
- Convert CDN WebP display copies losslessly to PNG at the desktop entrance, without changing Web upload behavior.
- Preserve old history entries and avoid importing known mismatched SKU references.
- Release feed targets dstarking/PromptOptimizer-tkwork and includes required bilingual notes.

## Breaking Changes / Upgrade Notes
- Requires separately installed BrowserSkill CLI/extension and a running daemon: bsk daemon start --foreground.
- Imported images are display copies, not verified supplier originals. Original images and complete detail-gallery collection are not guaranteed.
- Compliance checks are advisory, not official publishing approval. SEO recommendations are not verified live keywords.
- This release ships Windows x64 only. No macOS, Linux, extension ZIP or Windows portable ZIP is built.

## Developer Notes
- Keep context isolation and disabled Node integration; only allowlisted product/CDN URLs reach bounded main-process operations.
- P0 contains two single-dimension products and one two-dimension product. Long-term reliability, no-SKU and unavailable combinations remain outside verified coverage.
