# Prompt Optimizer v2.11.14

## 概括
- 避免模型内部标题被渲染成重复的 TikTok 商品卡模块。
- 仅将带编号的顶层输出标题识别为分块边界。
- 对重复编号分块进行合并，不再生成重复卡片。
- 强化商品卡提示词，要求每个编号分块标题只输出一次。

## 亮点
本次补丁解决模型在结果中增加内部标签或重复分块标题时，商品卡结果出现多个“商品识别”模块的问题。

## 产品更新
### Web
- 保持卖家侧结果块与预期中文标题的映射关系。
- 在避免标题重复卡片的同时，保留模型返回的完整内容。

## 修复
- 修复模型返回嵌套或重复标题时出现多个“商品识别”卡片的问题。
- 修复任意一到三级标题只要包含已知分块名称就被误判为新结果块的问题。

## 破坏性变更 / 升级说明
- 无。

## 开发者说明
- 结果分块现在要求使用带编号的一级或二级 Markdown 标题，例如 `## 01. Product Identification`。
- 重复编号分块会按分块 key 合并。
