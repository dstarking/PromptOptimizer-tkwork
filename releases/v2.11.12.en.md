# Prompt Optimizer v2.11.12

## Summary
- Moves TikTok product-card history out of the product-card workspace and into a dedicated history page.
- Adds a product-card history button in the upper-right workspace header.
- Keeps saved history entries loadable back into the product-card workflow.
- Shares the existing history preference storage and preserves the original history data format.

## Highlights
This patch keeps the TikTok product-card workspace focused on product inputs and generated results, preventing a growing history list from affecting the input layout.

## Product Updates
### Web
- Added a dedicated `/tiktok/product-card/history` page for viewing saved product-card optimization packages.
- Added an upper-right History button to the TikTok product-card workspace.
- Added a Back to Product Card action on the history page.
- Added Load actions that return to the product-card workspace and restore the selected saved result and optional seller inputs.

## Fixes
- Fixed product-card history content from occupying the workspace layout and covering optional product-input modules after image uploads.
- Centralized product-card history validation and loading so the workspace and history page use the same stored-entry contract.

## Breaking Changes / Upgrade Notes
- None.

## Developer Notes
- Product-card history remains stored under `session/tiktok-product-card/history/v1`.
- Original product images are still not stored in history and must be uploaded again before generating a new result from a saved entry.
