# Prompt Optimizer v2.11.14

## Summary
- Prevents nested model headings from being rendered as duplicate TikTok product-card modules.
- Recognizes only numbered top-level output headings as section boundaries.
- Merges repeated numbered sections instead of rendering duplicate cards.
- Strengthens the product-card prompt so each numbered section heading is emitted once.

## Highlights
This patch keeps TikTok product-card results readable when a model adds internal labels or repeats a section heading in its response.

## Product Updates
### Web
- Kept seller-facing result blocks mapped to the intended Chinese section titles.
- Preserved the full provider response content while preventing heading-only duplicate cards.

## Fixes
- Fixed multiple “Product Identification” cards appearing when nested or repeated headings were returned by the model.
- Fixed loose heading matching that treated any level-one to level-three heading containing a known section name as a new result block.

## Breaking Changes / Upgrade Notes
- None.

## Developer Notes
- Result boundaries now require a numbered level-one or level-two Markdown heading, such as `## 01. Product Identification`.
- Repeated numbered sections are merged by section key.
