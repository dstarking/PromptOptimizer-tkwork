# Prompt Optimizer v2.11.11

## Summary
- Adds a dedicated TikTok Shop Singapore pet-supplies product-card optimizer for cross-border sellers.
- Keeps the existing prompt-optimization features while providing a separate product-card workflow.
- Requires product images and accepts optional title, specifications, and supplier-description context.
- Produces split, seller-facing guidance together with English listing assets and AI image prompts.

## Highlights
This patch adds the first product-card optimization workflow for TikTok Shop Singapore pet-supplies sellers, using the configured multimodal text model and keeping the generated listing content ready for marketplace use.

## Product Updates
### Web
- Added image upload and Ctrl+V image-paste support, with product images required and additional product context optional.
- Added separate TikTok product-card navigation while retaining the existing application features.
- Added split result sections for product-card analysis, English title and description, a nine-image plan, and AI image prompts.
- Added product-card history support and kept history below dynamically expanding product-input content.
- Displayed seller-facing section titles in Chinese while keeping final product-card assets in English.

## Fixes
- Fixed the product-card input card height so uploaded images and optional fields no longer overlap the product-card history panel.
- Removed the duplicate model selector on the TikTok product-card page when the configured multimodal model is already available through the shared model switcher.

## Breaking Changes / Upgrade Notes
- None.

## Developer Notes
- The product-card system prompt is defined in `packages/ui/src/services/tiktok-product-card-prompt.ts`.
- The workflow uses the currently configured multimodal text model; no separate product-recognition model setting is introduced.
