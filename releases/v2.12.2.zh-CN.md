# Prompt Optimizer v2.12.2

## 概括
Windows 商品卡自动使用链接采集得到的可用商品参考图。

## 亮点
- 自动下载图片到模型输入区域，无需重复手动上传。
- 优先导入所选 SKU 图片，排除其他 SKU 专属参考图。

## 产品更新
### Desktop
- 已有图片时显示就绪状态，无可用图片时提示手动上传，保留上传与 Ctrl+V。
- 部分下载失败不影响可用图片，去重并限制最多 9 张。
### Web
- 无改动。
### Core/Infra
- 复用已有受限下载及图片预处理，补充回归测试。

## 修复
- 原采集只填充待导入图片列表，未自动用于生成。
- 清空或更换图片后，旧下载结果不再回填。

## 破坏性变更 / 升级说明
- 无迁移。仅 Windows x64 NSIS，未签名，包含自动更新元数据。
- 采集图片仍为未核实的展示副本，不承诺供应商原图。

## 开发者说明
- 不修改提示词、SKU 确认与图片下载安全规则。
